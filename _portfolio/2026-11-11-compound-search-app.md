### Features

- ✅ **Chinese + English queries** — Input Chinese names (苯, 甲苯, 阿司匹林) or English names (benzene, aspirin)
- ✅ **3-layer search engine** — 70+ built-in dictionary → MyMemory translation → OPSIN chemistry parser → PubChem structure image
- ✅ **Local search history** — Auto-saves last 5 searches (browser localStorage, never uploaded)
- ✅ **PWA installable** — Add to home screen, runs fullscreen like a native app
- ✅ **Zero dependencies** — Pure HTML + CSS + inline JS, no framework, single file
